# Diabetes Data Analysis & Machine Learning

## Overview

This project focuses on analyzing a diabetes dataset and applying machine learning techniques to predict diabetes-related outcomes.

The project includes exploratory data analysis, data cleaning, visualization and machine learning.

## Tools & Technologies

* Python
* VS Code
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn

## Project Workflow

1. Loaded and explored the dataset
2. Checked the data structure and missing values
3. Performed data cleaning and preprocessing
4. Conducted exploratory data analysis
5. Created visualizations to understand the data
6. Prepared the data for machine learning
7. Trained machine learning models
8. Evaluated model performance

## What I Learned

* Data preprocessing
* Exploratory Data Analysis (EDA)
* Data visualization
* Preparing datasets for machine learning
* Training machine learning models
* Evaluating model performance

## Project Files

* `diabetes.ipynb` – Complete analysis and machine learning notebook
* `diabetes_risk.csv` – Dataset used in the project 
* 'diabetes_cleaned.csv'- Cleaned dataset

## Note

This project is for educational purposes and is not intended for medical diagnosis or clinical decision-making.
